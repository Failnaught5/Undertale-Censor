MALE ALPHYS MOD - SIMPLE INSTALL

Put these files directly into your UNDERTALE game folder:

    xdelta3.exe
    Male-Alphys-v1.0.xdelta
    INSTALL_MALE_ALPHYS.bat
    UNINSTALL_MALE_ALPHYS.bat

The folder should also already contain UNDERTALE's normal data.win.

INSTALL:
Double-click INSTALL_MALE_ALPHYS.bat.

The installer will:
- Make data.win.backup the first time it runs.
- Build the modded file from that backup and the xdelta patch.
- Replace data.win only if xdelta finishes successfully.
- Leave the backup untouched.

UNINSTALL:
Double-click UNINSTALL_MALE_ALPHYS.bat.

IMPORTANT:
The original data.win must be from the same UNDERTALE version used to create the patch.
Do not delete data.win.backup unless you no longer need the original game file.
